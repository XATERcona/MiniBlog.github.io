# MiniBlog
LUMI.blog

Веб-приложение для публикации коротких статей с комментариями и лайками.

Технологии
HTML, CSS, JavaScript, GitHub Pages.

Функции
- создание статей с минимальным форматированием;
- лента статей с датой, счётчиком комментариев и сортировкой от новых к старым;
- редактирование и удаление статей (с подтверждением);
- комментарии с именем автора и текстом, удаление комментариев;
- лайк-переключатель с сохранением состояния;
- поиск по заголовку и тексту статьи;
- сохранение данных после перезагрузки страницы.

Запуск
Перейти на опубликованную версию.
